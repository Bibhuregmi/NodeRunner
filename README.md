# NodeRunner

> An interactive graph traversal visualizer built with React and Typescript 

---

## Overview

**NodeRunner** is a visual learning tool for graph algorithms.
Add nodes, connect them, and watch packets follow BFS / DFS traversal. 

---

## Features

- Add and position nodes on a canvas
- Create bi-directional connection between nodes.
- Send a packet from a source to target node. 
- Visualize **BFS traversal** (DFS coming soon!)
- Animated packet movement with step-by-step transitions. 

## Built with 

- React 
- Typescript
- SVG for dynamic graph rendering
- BFS algorithm (DFS coming soon)

---

## Installation 

```bash 
git clone https://github.com/Bibhuregmi/NodeRunner
cd NodeRunner
npm install 
npm run dev

```
